# Getting Started

Welcome to the **YAML Config** wiki. Whether you are a player trying to tweak some settings or a server administrator managing a modpack, this guide will walk you through everything you need to know.

YAML Config is a foundational library mod. While it doesn't add new blocks or items itself, it provides the powerful menu system that other mods use to let you configure their features.
