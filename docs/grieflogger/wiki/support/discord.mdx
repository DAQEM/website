For general help, discussions, and real-time support, the best place to connect with the community and the developer is through Discord.

### When to Use Discord

-   **Questions & Help:** If you're having trouble with the configuration, don't understand how a feature works, or need general advice.
-   **Suggestions:** If you have an idea for a new feature and want to discuss it before creating a formal feature request on GitHub.
-   **Showcasing:** Sharing how you use GriefLogger on your server.
-   **General Chat:** Connecting with other server administrators who use the mod.

<Admonition type="note">
    While you can ask for help with potential bugs on Discord, please be prepared to create a formal report on **[GitHub](./reporting-issues.mdx)** if the issue is confirmed to be a bug. The issue tracker is the official channel for tracking and fixing problems.
</Admonition>
