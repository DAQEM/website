The `arc:change_weather` reward type sets the current weather in the world.

## Parameters

<RewardParameterTable />

## Example

The following example makes it thunder when a player dies.

```json title="data/my_datapack/arc/dramatic_death.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_death",
    "rewards": [
        {
            "type": "arc:change_weather",
            "weather": "THUNDER",
            "duration": 6000
        }
    ]
}
```
