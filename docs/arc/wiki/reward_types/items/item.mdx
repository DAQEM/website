The `arc:item` reward type gives an item directly to the player's inventory.

## Parameters

<RewardParameterTable />

## Example

The following example will give the player an apple every time they break a dirt block.

```json title="data/my_datapack/arc/apple_from_dirt.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_break_block",
    "conditions": [
        {
            "type": "arc:block",
            "block": "minecraft:dirt"
        }
    ],
    "rewards": [
        {
            "type": "arc:item",
            "item": {
                "id": "minecraft:apple"
            }
        }
    ]
}
```
