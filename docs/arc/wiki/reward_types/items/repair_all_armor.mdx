The `arc:repair_all_armor` reward type repairs all equipped armor items.

<RewardParameterTable />

## Example

The following example repairs armor by 10 durability when gaining XP.

```json title="data/my_datapack/arc/mending_lite.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_pickup_item",
    "conditions": [
        {
            "type": "arc:entity_type",
            "entity_type": "minecraft:experience_orb"
        }
    ],
    "rewards": [
        {
            "type": "arc:repair_all_armor",
            "amount": 10
        }
    ]
}
```
