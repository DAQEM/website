The `arc:give_recipes` reward type unlocks specific crafting recipes for the player.

<RewardParameterTable />

## Example

The following example unlocks the iron pickaxe recipe when obtaining an iron ingot.

```json title="data/my_datapack/arc/unlock_iron.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_pickup_item",
    "conditions": [
        {
            "type": "arc:item",
            "item": "minecraft:iron_ingot"
        }
    ],
    "rewards": [
        {
            "type": "arc:give_recipes",
            "recipes": ["minecraft:iron_pickaxe"]
        }
    ]
}
```
