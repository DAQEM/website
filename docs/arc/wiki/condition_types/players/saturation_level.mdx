The `arc:saturation_level` condition type checks the player's current saturation level.

<ConditionParameterTable />

## Example

The following example gives speed if the player is fully saturated (saturation >= 20).

```json title="data/my_datapack/arc/full_belly_run.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_sprint",
    "conditions": [
        {
            "type": "arc:saturation_level",
            "saturation_level": 20,
            "comparison": ">="
        }
    ],
    "rewards": [
        {
            "type": "arc:effect",
            "effect": {
                "id": "minecraft:speed",
                "duration": 40
            }
        }
    ]
}
```
