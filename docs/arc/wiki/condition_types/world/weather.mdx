## Example

The following example gives speed when it is thundering.

```json title="data/my_datapack/arc/thunder_speed.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_walk",
    "conditions": [
        {
            "type": "arc:weather",
            "weather": "THUNDER"
        }
    ],
    "rewards": [
        {
            "type": "arc:effect",
            "effect": {
                "id": "minecraft:speed",
                "duration": 40
            }
        }
    ]
}
```
