The `arc:light_level` condition type checks the light level at the player's position.

## Parameters

<ConditionParameterTable />

## Example

The following example gives night vision if the light level is below 4.

```json title="data/my_datapack/arc/auto_night_vision.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_walk",
    "conditions": [
        {
            "type": "arc:light_level",
            "light_level": 4,
            "comparison": "<"
        }
    ],
    "rewards": [
        {
            "type": "arc:effect",
            "effect": {
                "id": "minecraft:night_vision",
                "duration": 200
            }
        }
    ]
}
```
