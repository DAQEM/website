The `arc:biome` condition type checks if the player is in one of the specified biomes.

<ConditionParameterTable />

## Example

The following example gives regeneration when standing in a desert.

```json title="data/my_datapack/arc/desert_regen.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_walk",
    "conditions": [
        {
            "type": "arc:biome",
            "biomes": [
                "minecraft:desert"
            ]
        }
    ],
    "rewards": [
        {
            "type": "arc:effect",
            "effect": {
                "id": "minecraft:regeneration",
                "duration": 20
            }
        }
    ]
}
```
