## Example

The following example gives the player a speed boost when they drink a Potion of Swiftness.

```json title="data/my_datapack/arc/boost_swiftness_potion.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_drink",
    "conditions": [
        {
            "type": "arc:item",
            "item": {
                "id": "minecraft:potion",
                "components": {
                    "minecraft:potion_contents": {
                        "potion": "minecraft:swiftness"
                    }
                }
            }
        }
    ],
    "rewards": [
        {
            "type": "arc:effect_amplifier_addition",
            "addition": 1
        }
    ]
}
```
