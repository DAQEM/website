The `arc:or` condition type is met if at least one of its nested conditions is met.

## Example

The following example will reward the player with a diamond if they break either a stone block or a dirt block.

```json title="data/my_datapack/arc/diamond_for_stone_or_dirt.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_break_block",
    "conditions": [
        {
            "type": "arc:or",
            "conditions": [
                {
                    "type": "arc:block",
                    "block": "minecraft:stone"
                },
                {
                    "type": "arc:block",
                    "block": "minecraft:dirt"
                }
            ]
        }
    ],
    "rewards": [
        {
            "type": "arc:item",
            "item": {
                "id": "minecraft:diamond"
            }
        }
    ]
}
```
