## Example

The following example gives the player a feather every time they jump.

```json title="data/my_datapack/arc/feather_jump.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_jump",
    "rewards": [
        {
            "type": "arc:item",
            "item": { "id": "minecraft:feather" }
        }
    ]
}
```
