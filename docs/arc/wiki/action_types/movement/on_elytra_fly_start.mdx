The `arc:on_elytra_fly_start` action type is triggered when a player starts flying with an elytra.

## Action Data

When this action is triggered, the following [action data](/docs/arc/wiki/action_data/index.mdx) is made available to be used by conditions and rewards:

<ActionDataTable />

## Example

The following example will give the player a Speed II effect for 10 seconds as long as they are flying with an elytra.

```json title="data/my_datapack/arc/speed_on_elytra_fly_start.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_elytra_fly_start",
    "rewards": [
        {
            "type": "arc:effect",
            "effect": "minecraft:speed",
            "duration": 200,
            "amplifier": 1
        }
    ]
}
```
