The `arc:on_horse_ride_stop` action type is triggered when a player stops riding a horse.

## Action Data

When this action is triggered, the following [action data](/docs/arc/wiki/action_data/index.mdx) is made available to be used by conditions and rewards:

<ActionDataTable />

## Example

The following example will give the player a Slowness I effect for 10 seconds as long as they are not riding a horse.

```json title="data/my_datapack/arc/slowness_on_horse_ride_stop.json"
{
    "holder": {
        "type": "arc:player",
        "id": "arc:player"
    },
    "type": "arc:on_horse_ride_stop",
    "rewards": [
        {
            "type": "arc:effect",
            "effect": "minecraft:slowness",
            "duration": 200,
            "amplifier": 0
        }
    ]
}
```
