If you need help, have found a bug, or want to ask a question, you've come to the right place. To ensure you get the help you need as quickly as possible, please use the appropriate channel for your inquiry.

-   **[Reporting Issues](./reporting-issues.mdx)**

-   For bugs, crashes, or unexpected behavior. This is the best way to ensure that problems with the mod get fixed. Please use our GitHub issue tracker for this.

-   **[Discord](./discord.mdx)**
-   For general questions, help with configuration, suggestions, and community discussion. This is the place for more informal conversation.

### Supporting the Project

X-Life is a free and open-source project developed by DAQEM. If you find the mod useful and wish to support its continued development, please consider donating through Ko-Fi.
