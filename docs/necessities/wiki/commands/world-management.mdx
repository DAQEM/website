---
title: World Management
---

Quick commands to manipulate the world environment.

## Time
Sets the world time.

| Command | Time Set | Permission |
| :--- | :--- | :--- |
| `/day` | 1000 | `necessities.command.time.day` |
| `/noon` | 6000 | `necessities.command.time.noon` |
| `/night` | 13000 | `necessities.command.time.night` |
| `/midnight` | 18000 | `necessities.command.time.midnight` |

**Default Level:** 2 (OP)

## Weather
Sets the world weather.

| Command | Effect | Permission |
| :--- | :--- | :--- |
| `/sun` | Clears weather | `necessities.command.weather.sun` |
| `/rain` | Starts rain | `necessities.command.weather.rain` |
| `/thunder` | Starts storm | `necessities.command.weather.thunder` |

**Default Level:** 2 (OP)
