# Installation

Item Restrictions is available for **Forge**, **Fabric**, and **NeoForge**.

## Requirements

Ensure you have the following installed for your specific loader and Minecraft version:

1.  **Minecraft** (Supported versions listed on the download page)
2.  **Item Restrictions** mod jar.
3.  **Arc Lib** (Required Dependency).
4.  **YAML Config** (Required Dependency).
5.  **Architectury API** (Required Dependency).
6.  **Fabric API** (If using Fabric).

## Setup

1.  Download the mods from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/item-restrictions) or [Modrinth](https://modrinth.com/mod/item-restrictions).
2.  Place all jar files into your `mods` folder.
3.  Launch the game.

Upon a successful launch, the mod will generate a configuration folder at `config/itemrestrictions/`.
