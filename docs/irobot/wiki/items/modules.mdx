Modules are special items that can be installed in a robot's module slots to grant it new abilities or enhance its existing stats. Each robot has two module slots.

<Admonition type="note">
    All modules first require a [**Module Base**](components.mdx#module-base) to be crafted.
</Admonition>

## Attribute Modules

These modules provide direct boosts to a robot's core stats.

### Speed Boost Module
Increases the robot's movement speed.
