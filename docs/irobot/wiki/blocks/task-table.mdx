The **Task Table** is the central block for programming your robots. It provides a user interface to select a specific task and, if necessary, bind it to a defined area from a Task Marker.

### Functionality
Right-clicking the Task Table opens a GUI where you can:
1. **Select a Task:** Click on one of the icons to choose a task (e.g., Mining, Farming).
2. **Insert a Task Marker:** For tasks requiring an area, place a configured Task Marker item in the input slot.
3. **Create a Task Item:** A Task Item will be generated in the output slot, encoded with the selected task and area data. This item can then be placed in a robot's task slot to assign the job.
