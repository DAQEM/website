Installing the iRobot mod is a straightforward process. It is a server-side mod, but it must also be installed on the client to see the custom models and interfaces.

## Requirements
Before installing, please ensure you have the following:

*   **Minecraft Version:** `1.21.6` or later compatible versions.
*   **Mod Loader:** A recent version of Fabric or NeoForge.
*   **Dependencies:**
*   [Architectury API](https://modrinth.com/mod/architectury-api)
*   [YAML Config](https://modrinth.com/mod/yaml-config)
*   [UI Lib](https://modrinth.com/mod/ui-lib)
*   [GeckoLib](https://modrinth.com/mod/geckolib)

<Admonition type="danger" title="Install All Dependencies!">
    The mod will not launch without **all** of its required dependencies. Make sure you download and install the correct version of each one for your chosen mod loader and Minecraft version.
</Admonition>

## Installation Steps

1.  **Download the Correct Files:**
Download the iRobot mod and all its dependencies for your specific mod loader (Fabric or NeoForge). You can find the files on Modrinth or CurseForge.

2.  **Install the Mod Loader:**
Ensure you have the latest version of Fabric or NeoForge installed for your server and/or client.

3.  **Place Files in `mods` Folder:**
Move all the downloaded `.jar` files into your `mods` folder. If this folder doesn't exist, create it.

4.  **Start Your Game or Server:**
Launch the game or server. The mod will generate its configuration files in the `config` folder on the first run.
