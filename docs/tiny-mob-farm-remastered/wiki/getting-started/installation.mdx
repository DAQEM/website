# Installation Guide

Installing Tiny Mob Farm Remastered is straightforward, but it requires a few dependencies to function correctly.

## Dependencies

You must install the following mods for Tiny Mob Farm to launch:

*   **[Architectury API](https://www.curseforge.com/minecraft/mc-mods/architectury-api)** - Required for cross-platform compatibility.
*   **[YAML Config](https://www.curseforge.com/minecraft/mc-mods/yaml-config)** - Required for the configuration system.
*   **[UI Lib](https://www.curseforge.com/minecraft/mc-mods/ui)** - Required for the in-game user interface.

## Steps

1.  Download the `.jar` file for **Tiny Mob Farm Remastered** from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/tiny-mob-farm-remastered) or [Modrinth](https://modrinth.com/mod/tiny-mob-farm-remastered).
2.  Download the **dependencies** listed above for your specific mod loader.
3.  Place all files into your Minecraft instance's `/mods` folder.
4.  Launch the game!
