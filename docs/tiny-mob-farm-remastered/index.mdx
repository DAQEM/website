**Tiny Mob Farm Remastered** is a Minecraft mod that condenses the massive, lag-inducing mob grinders of vanilla Minecraft into a single, neat block.

Instead of building massive dark rooms, drop towers, or water flush systems, simply capture a mob in a **Lasso**, place it into a **Mob Farm** block, and watch the loot roll in.

## Key Features

*   **Lag Reduction:** Drastically reduces server strain by removing the need for hundreds of entities to spawn and die constantly.
*   **Compact Design:** Fits entirely within a single block space.
*   **Tiered Progression:** Upgrade your farms from slow wooden crates to rapid-fire ultimate technologies.
*   **Automation Friendly:** Fully compatible with Hoppers, pipes, and storage systems.
*   **Highly Configurable:** Server owners can tweak speeds, durability, and mob blacklists.
